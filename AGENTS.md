# Project Guidelines & Rules

## Commit & Push Rule
* Commit and push to the project's GitHub repo (`RaptorJesus67/V2P-Photo-Extractor`) after every change made by the system.

## Gradle Configuration Rule
* ALWAYS use Gradle version 9.3.1 or newer.

## Version & Changelog Rule
* ALWAYS update the "Update Log" (`AppVersionInfo.changelog` in `MainActivity.kt` and `AppConfig.versionNumber`) with the current `versionCode` and `versionName` along with the bullet points of updates made since the last version whenever updating versions or making new release builds.
